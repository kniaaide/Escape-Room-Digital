# Escape-Room-Digital

Proyecto de juego tipo escape room enfocado en una experiencia digital interactiva y narrativa.

## Descripción

El repositorio presenta una propuesta de juego donde el usuario avanza por una serie de retos digitales, busca soluciones y completa objetivos para alcanzar la victoria.

## Funcionalidades

- Interfaz de juego digital.
- Pistas y enigmas.
- Progresión por niveles o escenarios.
- Experiencia interactiva.

## Tecnologías

- C#
- Windows Forms
- .NET

## Ejecución

1. Abre la solución en Visual Studio.
2. Compila el proyecto.
3. Ejecuta la aplicación.
